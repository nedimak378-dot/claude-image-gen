# Image Generation Skill

**Description:** Generates an image based on a user-provided text prompt using the Google Gemini API.

**Tool:** `main.py`

**Usage:**
This skill uses a Python script to call the Google Gemini API for image generation. You need to have a valid Google API key with the "Google AI for Developers" (Gemini) API enabled.

**Arguments:**
- `prompt` (string, required): The text description of the image you want to create.

**Example:**
`python3 main.py --prompt "A futuristic city with flying cars, photorealistic"`
